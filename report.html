Лабораторная работа № 5

Каталог товаров

Выполнил(а) _________________________ · Группа __________

Цель

Загрузить каталог товаров из Fake Store API и реализовать фильтрацию по категориям и диапазону цен.

Ход работы

ProductList загружает товары через fetch в useEffect и отменяет запрос через AbortController. ProductCard показывает изображение, название, описание и цену. Для отсутствующих изображений предусмотрена заглушка. Интерфейс показывает загрузку, сетевую ошибку и пустую выдачу.

В Filters можно выбрать несколько категорий, ввести обе границы цены вручную или выставить их ползунками. Валидация выполняется по кнопке применения и отклоняет отрицательные числа и диапазон с максимумом ниже минимума.

Результат проверки

Обработчик API проверен с подменённым HTTP-ответом. В демонстрационном режиме проверены ошибка при цене −1 и выдача из двух товаров при выборе electronics и jewelery с минимумом 50 USD.

Воспроизведение

Распакуйте архив, выполните npm.cmd ci и npm.cmd run dev из папки с package.json. Откройте адрес, указанный Vite в терминале. Если API недоступен, включите демонстрационные товары. Отметьте две категории, задайте цену от 50 USD и примените фильтры.
